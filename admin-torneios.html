Passos para publicar as alterações

  1. Adicione, edite ou remova os torneios acima.
  2. Clique em Baixar torneios.json atualizado.
  3. Abra o torneios.json no GitHub, clique no lápis, substitua o conteúdo pelo conteúdo do arquivo baixado e faça o commit. Você também pode usar a opção de upload do GitHub para substituir o arquivo.
  4. Aguarde o GitHub Pages atualizar e confira o formulário de inscrição.

O editor mantém as alterações na memória desta página até você recarregá-la. Baixe o JSON antes de sair.
